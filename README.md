# BNMcreative v1.2

## Smart Matching Update
- 89 organized starter activities
- Smarter weighted matching
- Compact activity cards
- Expandable details for supplies, instructions, tips, and match reasoning
- Search and filters in Browse Ideas
- Clean multi-file structure for easier future edits

## Files
- `index.html` — page structure
- `css/variables.css` — colors and design tokens
- `css/base.css` — global styles and animations
- `css/components.css` — buttons, cards, filters, reusable pieces
- `css/pages.css` — page-specific layouts
- `data/activities.js` — every activity in one editable list
- `js/matching.js` — recommendation scoring
- `js/cards.js` — activity card creation
- `js/questionnaire.js` — questions and navigation
- `js/browse.js` — search and filters
- `js/app.js` — startup and page switching
